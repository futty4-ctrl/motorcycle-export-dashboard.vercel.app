## 1. はじめに

### アプリの目的

- **車両の一覧・ステータス管理**（Supabase 連携）
- **BDS個票のAI査定**（画像アップロード → GO/NG/CAUTION 判定・入札上限算出）
- **在庫・古物台帳の統合管理**（新規登録・ステータス変更・QRコード発行）
- **市場価格マスター**（車種別相場の参照・追加・編集・削除）
- **BDS入札上限のシミュレーション**（ヤフオク相場・整備代・希望利益から計算）
- **請求書・見積書の作成・印刷**
- **書類・ドキュメントの一覧管理**
- **システム設定**（プロフィール・API・オークション・通知など）

### 推奨環境

- モダンなブラウザ（Chrome, Edge, Firefox, Safari）
- 画面幅は広め（サイドバー + メインコンテンツ）を推奨

## 3. ダッシュボード

**パス**: `/`

### 表示内容

- **月利目標進捗**
  - 今月の売却粗利と目標額（100万円）の比較
  - 進捗バーと「あと〇円」表示

- **KPIカード（3つ）**
  - 総車両数
  - 在庫・出品中台数
  - 今月売却台数

- **直近の査定履歴**
  - 最新5件の車両（車名・日付・仕入価格・ステータス）
  - 行クリックで車両詳細へ（`/vehicle/[id]`）
  - 「査定ページへ →」で `/assess` へ

- **相場トレンド**
  - 車種ごとのトレンド（↑/→/↓）とメモ
  - 「相場DBへ →」で市場価格ページへ

### データの出所

- Supabase の車両データ（`getVehiclesFromSupabase`）を使用
- 接続状態は画面上部に「Supabase ●/○」で表示

## 4. AI査定

**パス**: `/assess`

BDS（バイクオークション）の個票スクリーンショットをアップロードし、AIで解析して「GO / NG / CAUTION」判定と入札上限額を算出します。

### 手順

1. **画像を選ぶ**
   - 「BDS個票スクショ」エリアをクリックするか、ファイルをドロップ
   - 対応形式: PNG / JPG / WebP / PDF

2. **査定する**
   - 画像選択後、「査定する」ボタンをクリック
   - 画像が Base64 で `/api/assess` に送られ、AI（Gemini 等）で解析されます

3. **結果を確認**
   - **判定**: GO（緑）/ NG（赤）/ CAUTION（黄）と理由
   - **BDS 入札上限額**: 円表示
   - **車両情報**: 車種・年式・走行・排気量・エンジン状態など
   - **損傷サマリ**: あれば表示
   - **収支シミュレーション**: 仕入価格・総コスト・想定売却・粗利の範囲

4. **Supabaseに保存する（任意）**
   - 「Supabaseに保存する」をクリック
   - `/api/assess/save` で DB に保存され、「✓ Supabaseに保存済み」と表示

### 必要な設定

- **Gemini API**: `GOOGLE_GEMINI_API_KEY`（または Anthropic 等、実装に依存）
- **Supabase**: 保存する場合は `NEXT_PUBLIC_SUPABASE_URL` と `SUPABASE_SERVICE_ROLE_KEY`（または ANON_KEY）を設定

## 5. 在庫管理

**パス**: `/inventory`

在庫車両と古物台帳をまとめて管理します。

### 機能概要

- **ステータス**: 未処理 / 出品準備中 / ヤフオク出品中 / 売約済み
- **カテゴリ**: 車体 / パーツ
- **一覧**: 管理番号・車名・仕入価格・状態・ステータス
- **フィルター**: 「すべて」または各ステータスで絞り込み
- **新規登録**: フォームで車両情報と古物台帳（受入情報）を入力

### 新規登録の手順

1. 「+ 新規登録」をクリック
2. **車両情報**
   - カテゴリ、仕入日、メーカー、車種、型式、車台番号、仕入価格、状態メモ
3. **古物台帳（受入情報）**
   - 売主氏名・年齢・住所・職業・本人確認方法
4. 「登録する」をクリック
5. 登録後、**管理番号**が発行され、**QRコード**と**URL**が表示されます
   - 「URLコピー」「QR保存」で共有・印刷可能

### ステータス変更

- 一覧の各行の「ステータス」列でドロップダウンを選択し、ステータスを変更すると DB に保存されます。

### 詳細ページ

- 管理番号（例: 在庫の管理コード）をクリックすると `/inventory/[管理番号]` の詳細ページに遷移します（実装により表示内容は異なります）。

### データの出所

- Supabase（`lib/inventory-supabase` の `fetchInventoryItems`, `insertInventoryItem`, `updateInventoryItemStatus`）

## 6. アナリティクス

**パス**: `/analytics`

収支の月別グラフ・目標進捗・仕入れ余力を確認します。

### 表示内容

- **KPI**
  - 累計実績粗利・累計予想粗利・月利目標達成率

- **月利目標進捗バー**
  - 累計実績と目標（100万円）・仕入れ余力

- **修理費：予想 vs 実際**
  - 車両ごとの棒グラフ（予想修理費・実際の修理費）

- **利益：予想 vs 実際**
  - 車両ごとの棒グラフ（予想利益・実際の利益）

- **誤差一覧テーブル**
  - 車両名・予想利益・実際の利益・ズレ（差額）
  - 車両名クリックで `/vehicle/[id]` へ

### データの出所

- `getAnalyticsData()`（Supabase 等の実績・予想データ）

## 7. 市場価格

**パス**: `/market-prices` または `/market`（ルート設定による）

車種ごとの相場データ（メーカー・車種・年式・コンディション・ソース・平均価格・トレンドなど）を一覧・検索・編集します。査定や入札上限の参考にします。

### 表示内容

- **サマリ**
  - 登録車種数・平均単価・上昇傾向件数・下降傾向件数

- **ツールバー**
  - 検索（車種・メーカー）
  - メーカー・コンディション・ソース（ヤフオク/BDS/カチオク/JBA/手動）でフィルター
  - 「＋ 追加」「CSV書出」「リセット」

- **テーブル**
  - 列: メーカー・車種・年式・状態・ソース・平均相場・最低・最高・件数・トレンド・更新日・操作（編集/削除）
  - 列ヘッダークリックでソート
  - チェックボックスで複数選択 → 「選択削除」可能（実装による）

### 追加・編集

- 「＋ 追加」で新規レコードのモーダルを表示
- 各行の「編集」で既存レコードを編集
- メーカー・車種・年式・コンディション・ソース・平均/最低/最高価格・サンプル数・トレンド・メモなどを入力して保存

### データの出所

- Supabase（`lib/api` / `lib/queries` の `getMarketPrices`, `upsertMarketPrice`, `deleteMarketPrice`）
- ブラウザから直接 Supabase にアクセスするため、`NEXT_PUBLIC_SUPABASE_ANON_KEY` が必要です。

## 8. BDSシミュレーター

**パス**: `/bds-simulator`

ヤフオクの想定落札額・整備代・希望利益から「BDSでの入札上限額」を計算します。

### 入力項目

- **車両情報**: メーカー・状態（実働/不動/部品取り）・車名・型式
- **価格設定**
  - ヤフオク平均落札額（円）
  - 想定整備・パーツ代（円）
  - 希望利益（円）

### 計算ロジック

- ヤフオクシステム手数料 = 落札額の 10%
- 出品経費 = 10,000 円（固定）
- **BDS入札上限額** = ヤフオク平均落札額 − (手数料 + 出品経費 + 整備代 + 希望利益)

### 表示内容

- 計算内訳（手数料・出品経費・整備代・希望利益）
- BDS入札上限額（0 以下なら「条件を見直してください」と表示）

### 保存・履歴

- 「保存する」で現在の条件と結果をブラウザの **localStorage** に保存
- 「保存履歴」テーブルで日時・車両・状態・ヤフオク相場・入札上限を確認
- 「クリア」で履歴を全削除

※ 履歴は端末内のみで、サーバーや Supabase には送信されません。

## 9. 請求書・見積書

**パス**: `/invoices` または `/invoice`

請求書・見積書を作成し、プレビューして印刷用HTMLを出力します。

### 画面構成

- **種別**: 請求書 / 見積書
- **日付・宛先・件名**
- **振込先**（請求書の場合、複数行テキスト）
- **明細**: 摘要・数量・単位・単価（行の追加・削除可能）
- **税率**: ％指定で小計・税・合計を自動計算
- **備考**

### 操作

1. 種別・日付・宛先・件名・明細などを入力
2. **プレビュー**: 右側（または同一画面）でリアルタイムプレビューを確認
3. **保存**: Supabase の `invoices` テーブルに保存（実装による）
4. **印刷**
   - 「印刷」ボタンで、印刷用の HTML を別ウィンドウに出力
   - 別ウィンドウで自動的に印刷ダイアログが開き、印刷後にウィンドウを閉じる想定

### 印刷レイアウト

- A4縦・余白を抑えたレイアウト
- タイトル・宛先・自社情報・件名・合計金額（請求書）・振込先・明細テーブル・小計・税・合計・備考

## 10. ドキュメント

### 表示モード

※ 現在はモックデータで表示されている可能性があります。実際の保存先は実装により異なります。

## 11. 設定

**パス**: `/settings`

タブで次の項目を設定します。

| タブ | 内容 |
|------|------|
| **プロフィール** | 表示名・会社名・メール・タイムゾーン・表示通貨 |
| **API設定** | Gemini API キー・モデル、OpenAI API キー、Google Sheets 連携（スプレッドシートID） |
| **オークション** | 査定デフォルト値（マージン率・整備バッファ・ヤフオク手数料・輸出経費・デフォルトコンディションなど） |
| **通知** | LINE・メールのON/OFF、新規・入札・落札などの通知設定、LINEトークン |
| **エクスポート** | エクスポート形式（CSV等）・エンコーディング・自動同期・同期間隔 |
| **危険な操作** | データ削除・リセットなど（使用時は注意） |

各項目を入力・選択し、「変更を保存」で保存します。保存先（ローカルストレージ・Supabase・環境変数など）は実装により異なります。

## 12. 環境変数・API

### 主な環境変数（.env.local）

| 変数名 | 用途 |
|--------|------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase プロジェクトURL |
| `SUPABASE_SERVICE_ROLE_KEY` | サーバー用（絶対にクライアントに露出しない） |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ブラウザ用（市場価格・在庫など lib/api から使用） |
| `GOOGLE_GEMINI_API_KEY` | AI査定（/api/assess） |
| `GEMINI_MODEL` | 使用モデル（例: gemini-2.5-flash） |
| `GOOGLE_SHEETS_SPREADSHEET_ID` | Google Sheets 連携（任意） |
| `ANTHROPIC_API_KEY` | BDS査定で Anthropic を使う場合（任意） |
| `FALLBACK_USD_JPY` | 為替フォールバック（eBay 円換算など） |
| `YAHOO_AUCTION_ID` | ヤフオク出品モニター用 |
| `GAMI_BOOKMARKLET_API_KEY` | ブックマークレット API 認証 |

詳細はプロジェクトルートの `.env.example` を参照してください。

### API ルート

- **POST /api/assess**: BDS個票画像（Base64）を受け取り、AI査定結果（JSON）を返す
- **POST /api/assess/save**: 査定結果を Supabase の assessments テーブル等に保存
