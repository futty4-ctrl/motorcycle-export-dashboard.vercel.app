## 2. 在庫管理

**パス**: `/inventory`

BDSで仕入れた車両を登録・管理します。古物台帳の記録もここで行います。

### 新規登録の手順

1. 「＋ 新規登録」をクリック
2. 車両情報を入力
   - 仕入日・メーカー・車種・型式・車台番号
   - **仕入価格**（BDSの落札額）
   - BDS会場（大阪 / 関東 / 九州）
   - 排気量区分
   - 状態メモ
3. 古物台帳（売主情報）を入力
   - 売主氏名・年齢・住所・職業・本人確認方法
4. 「登録する」をクリック → 管理番号が自動発行されます

### ステータスの流れ

```
未処理 → 出品準備中 → ヤフオク出品中 → 売約済み
```

### 売却を記録する

ヤフオクで落札されたら：
1. 一覧の該当車両をクリック
2. 「売却価格」と「売却日」を入力して保存
3. ステータスが自動で「売却済み」になり、**相場マスターが自動更新**されます

## 3. 相場リサーチ

**パス**: `/research`

ヤフオクの落札履歴から特定車種の相場レンジを取得します。

### 使い方

1. 検索欄に車種名を入力（例: `モンキー Z50`）
2. 「検索」をクリック
3. 平均落札価格・相場レンジ（25〜75%）・中央値が表示されます

### フィルター

| 項目 | 説明 |
|------|------|
| カテゴリ | オートバイ車体（推奨）/ 全体 / アクセサリー |
| 最低・最高価格 | 価格帯で絞り込み |
| 除外キーワード | 「ジャンク,パーツ,部品」など不要な出品を除外 |
| 取得件数 | 20 / 50 / 100 件 |

### 相場マスターに登録

検索結果の「相場マスターに登録 →」ボタンで、取得した平均値を市場価格マスターに保存できます。BDSボーダー計算で使えるようになります。

## 4. 125cc 利益スコアボード

**パス**: `/scoreboard`

125cc車種（25車種）のヤフオク相場を一括スキャンし、BDSボーダーと利益ポテンシャルをランキング表示します。

### 使い方

1. BDS会場・目標粗利・除外キーワードを設定
2. 「スキャン開始」をクリック
3. 全25車種を順番にスキャン（約3〜4分）
4. 完了後、BDSボーダー順・ヤフオク相場順・利益額順で並べ替えできます

### 活用方法

- **BDSボーダーが高い車種** = BDS会場で高値まで入札できる = 仕入れ余地が大きい
- **「全件を相場マスターに登録」**ボタンで一括登録できます

### 対象車種カテゴリ

| カテゴリ | 車種例 |
|---------|--------|
| 4mini | モンキー・ゴリラ・エイプ・ダックス・シャリー |
| カブ | C50・C70・C90・110・クロスカブ |
| スクーター | アドレスV125・シグナスX・PCX・NMAX |
| スポーツ | グロム・CBR125R・Z125・KSR110 |
| オフ | XR100モタード・CRF100F・TTR125 |

## 5. BDS 入札ボーダー計算

**パス**: `/bds-border`

「ヤフオク落札相場からBDSでいくらまで入札できるか」を逆算します。BDS会場でリアルタイムに使う計算ツールです。

### 使い方

1. **ヤフオク売却相場**を入力
   - 「相場マスターから選択」または「手動入力」
2. **BDS設定**を選択
   - 会場（大阪 / 関東 / 九州）→ 送料が自動反映
   - 会員種別（A / C）
   - 排気量区分
   - 目標粗利（デフォルト¥25,000）
3. **MAX BID BORDER**（最大入札ボーダー）が表示されます

### BDS現在価格チェック

「BDSの現在価格」欄に今の競り値を入れると：
- **✅ 買い** — ボーダー以下なので入札継続してOK
- **❌ 見送り** — ボーダーを超えているので撤退

### コスト計算式

```
ヤフオク売却相場
  − 送料（会場→堺）
  − BDS落札料（会員種別・落札額による）
  − ヤフオク出品手数料（¥1,980 + 広告¥700）
  − 目標粗利
= BDSボーダー（最大入札額）
```

## 7. 市場価格マスター

**パス**: `/market`

車種ごとの相場データを管理します。BDSボーダー計算の参照元になります。

### 機能

- 車種・メーカーで検索・フィルター
- レコードの追加・編集・削除
- CSV書き出し
- 列ヘッダーでソート

### 自動更新のタイミング

以下のときに自動でデータが更新されます：
1. 相場リサーチで「相場マスターに登録」を押したとき
2. スコアボードで「全件を相場マスターに登録」を押したとき
3. **在庫管理で売却価格を記録したとき**（同車種の実売データから自動計算）

## 8. 売却実績

**パス**: `/performance`

仕入れ〜売却の実績を集計・分析します。

### 表示内容

| セクション | 内容 |
|-----------|------|
| KPI 4枚 | 累計売却台数・累計粗利・平均粗利/台・平均在庫日数 |
| 月次グラフ | 過去12ヶ月の粗利推移と台数 |
| BDS会場別 | 大阪/関東/九州それぞれの粗利・台数 |
| 車種別ランキング | 平均粗利順。目標¥25K超えたらオレンジ表示 |

### 粗利の計算式

```
実際の粗利 = 売却額 − 仕入額 − BDS落札料（A会員） − ヤフオク手数料 − 送料
```

### 活用方法

- **車種別ランキング**で「実際に稼いでいる車種」が分かります
- **平均在庫日数**が短い車種 = 回転が速い = 優先して仕入れるべき車種
- 在庫日数が20日超えている車種は売れにくい = 仕入れを絞る判断材料に

## 13. 請求書・見積書

**パス**: `/invoices`

請求書・見積書を作成して印刷用HTMLを出力します。

### 操作手順

1. 種別（請求書 / 見積書）を選択
2. 日付・宛先・件名を入力
3. 明細行を入力（品目・数量・単価）
4. 税率を設定 → 合計が自動計算されます
5. 「印刷」ボタンで印刷ダイアログを表示

## よくある使い方（日常フロー）

### BDS会場に行く前

1. `/scoreboard` でスキャン → 今日狙う車種のボーダーを確認
2. スマホで `/bds-border` を開いておく

### BDS会場で

1. `/bds-border` を開く
2. 相場マスターから車種を選択 → ボーダー表示
3. 「BDSの現在価格」に競り値を入れて「買い/見送り」を即判断

### 仕入れ後

1. `/inventory` で新規登録（仕入価格・車種・会場を入力）

### ヤフオクで落札されたら

1. `/inventory` の該当車両を開く
2. 売却価格と売却日を入力して保存
3. 相場マスターが自動更新されます

### 月末に

1. `/performance` で車種別ランキングを確認
2. 利益が出ていない車種・売れにくい車種を把握して次月の仕入れ方針を決める
