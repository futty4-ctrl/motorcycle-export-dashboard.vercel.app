# 販売ルール

## ヤフオク出品ルール

| 項目 | 内容 |
|------|------|
| スタート価格 | 1円スタート |
| 終了曜日・時間 | 日曜21時終了 |
| 出品期間 | 7日間 |
| 広告 | 1日100円 × 7日間 = 700円 |
| 動画 | YouTube動画リンクを必ず掲載（不動車含む） |

## 出品テンプレ

出品テンプレは `/yahoo-template` ページから生成。

生成される文面の構成：
1. 冒頭の挨拶
2. 出品理由
3. 車両情報
4. 車両の状態
5. YouTube動画リンク（必須）
6. 動作確認済み項目
7. 特記事項
8. 取引について
9. ご購入前にご確認ください
10. 締め
