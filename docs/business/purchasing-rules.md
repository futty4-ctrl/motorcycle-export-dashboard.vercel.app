# 仕入れルール

## 基本ルール

| 項目 | 内容 |
|------|------|
| 仕入上限 | 15万円以内 |
| 仕入れ先 | BDS関東・BDS九州 |
| 引き取り拠点 | 大阪府堺市 |
| メイン車種 | ネイキッド・オフ車・4ミニ |

## ボーダー計算

入札上限（ボーダー）は `components/bds-border-content.tsx` のロジックで算出。

**計算式（概念）**:
```
ボーダー = ヤフオク売り相場 − 送料 − BDS手数料 − ヤフオク手数料(¥2,680) − 目標粗利
```

- 送料・BDS手数料の詳細テーブルは `bds-border-content.tsx` を参照
- 会員種別：A会員 or C会員で手数料が異なる

## 仕入れ判断基準

1. ヤフオク相場を確認（市場価格DBまたは相場リサーチページ）
2. ボーダー計算ページでボーダー価格を算出
3. BDS現在入札額がボーダー以下なら「買い」
4. 状態（良好・普通・難あり）を必ず確認

## 主力車種の相場目安

| 車種 | 状態 | 備考 |
|------|------|------|
| ゴリラ | 良好・普通・難あり | 要都度確認 |
| モンキー | 良好・普通・難あり | 要都度確認 |
| エイプ | 良好・普通・難あり | 要都度確認 |
| アドレスV125 | 良好・普通・難あり | 要都度確認 |

※ 相場は市場価格ページ（`/market`）で管理
