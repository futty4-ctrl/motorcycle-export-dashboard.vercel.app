# サイトの出来上がり（構成・見た目）

## ローカルで表示する方法

ターミナルで以下を実行し、ブラウザで **http://localhost:3000** を開いてください。

```powershell
cd c:\Users\user\Downloads\motorcycle-export-dashboard
npm run dev
```

「Ready」と表示されたら、ブラウザで **http://localhost:3000** にアクセスします。

---

## 全体構成

- **アプリ名**: MotoExport Pro（バイク輸出ダッシュボード）
- **PWA**: `manifest.json` あり。スマホでホームに追加可能。
- **テーマ**: デフォルトはダークモード（黒基調）。ヘッダーからライト/ダーク切替可能。
- **レイアウト**: スマホは下タブナビ、PC（lg以上）は左サイドバー。

---

## 1. トップ（ダッシュボード） `/`

- **ヘッダー（固定）**
  - 左: ロゴ「M」（スマホのみ）＋ MotoExport
  - 中央: 検索「車両、VIN、オークション検索...」
  - 右: テーマ切替（太陽/月アイコン）、通知（ベル）

- **メイン**
  - タイトル: 「ダッシュボード」＋ 日付・オークション週間
  - **サマリーカード 3枚**（横並び）
    - 入札中（件数）
    - 在庫数（件）
    - 月間利益（円 ＋ USD）
  - **車両リスト**
    - 各車両カード: サムネイル、車名、年式・走行・評価、ステータス（仕入中/在庫あり/出品中/発送中/売却済）、利益バー（¥/USD）、メニュー（⋯）
    - タップで車両詳細へ

- **スマホのみ**
  - 下部固定: ホーム / 在庫 / 出品 / 設定
  - 右下 FAB: 新規追加など

- **PCのみ**
  - 左サイドバー: ダッシュボード、オークション・プレビュー、在庫管理、予想 vs 実績、eBay出品、設定（折りたたみ可）

---

## 2. 車両詳細 `/vehicle/[id]`

- **基本情報**: 画像、車名、年式・走行・評価、ステータス（ドロップダウンで変更）
- **BDS・写真**
  - BDS URL 取り込み、写真一括解析ボタン、「**Bad Case として保存**」ボタン（解析結果があるとき）
  - 解析結果: 外装/フレーム/エンジン評価（A–E）、リスク箇所（写真番号・bbox）、外装の傷・エンジン腐食・消耗品・カスタムパーツ・eBay高値パーツ、4mini鑑定（ブランドパーツ・厳格修理費）、AIズーム・インスペクション（bbox 切り出し表示）
- **査定・利益比較**
  - 落札額・陸送費・ヤフオク/eBay 予想価格・手数料・送料入力
  - ヤフオク車体 vs eBay パーツの利益比較、推奨シナリオ、目標利益達成（Go/No-Go）
- **実際の実績**: 実際修理費・売却価格・利益（保存可能）
- **パーツリスト**: 追加・一覧

## 4. デザインのポイント

- **Tailwind + shadcn/ui**: カード、ボタン、ダイアログ、入力は shadcn ベース。
- **ダーク時**: 背景 `220 25% 7%`、カード `220 25% 10%`、ゴールド系アクセント（`accent`）。
- **モバイル**: タップしやすいボタン・下タブ、セーフエリア考慮の FAB。
