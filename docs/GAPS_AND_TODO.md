- **PWA アイコン**: `public/icon-192.png` と `public/icon-512.png` を配置済み。

## 4. 実装済みで問題ない点

- 写真解析・厳格鑑定・4mini鑑定・BDS査定・利益比較（ヤフオク vs eBay）は一通り実装済み。
- プレミアムパーツ加算・Bad Case 保存と次回解析への反映・解像度ルール・重点ズーム解析も実装済み。
- データアクセスはすべて Server Actions + サービスロールのため、現状のままでクライアントから DB が直叩きされる経路は無い。
- 車両 0 台のときは VehicleList で「車両が見つかりません」が表示される（フォールバックは `vehiclesProp` が null のときのみ）。
