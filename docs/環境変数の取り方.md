# 環境変数はどこにある？（キーの取り方）

`.env.local` に書く値が、どの画面のどこにあるかをまとめました。

---

## 1. Supabase の2つ

**NEXT_PUBLIC_SUPABASE_URL** と **SUPABASE_SERVICE_ROLE_KEY** は、Supabase のダッシュボードから取ります。

### 手順

1. **https://supabase.com** にログイン
2. 使う **プロジェクト** を開く（なければ「New project」で作成）
3. 左メニュー **Settings**（歯車アイコン）→ **API**
4. 次の2つをコピー

| 環境変数 | 画面での名前 | 場所 |
|----------|--------------|------|
| **NEXT_PUBLIC_SUPABASE_URL** | **Project URL** | 「Project URL」の右にある URL をそのままコピー（例: `https://abcdefgh.supabase.co`） |
| **SUPABASE_SERVICE_ROLE_KEY** | **service_role** | 「Project API keys」の一覧のうち、**service_role** の行の「Reveal」を押して表示された長い文字列をコピー |

⚠️ **service_role** は権限が強いキーです。Git に上げたり、人に渡したりしないでください。`.env.local` にだけ書きます。

---

## 2. Google スプレッドシートの ID

**GOOGLE_SHEETS_SPREADSHEET_ID** は、スプレッドシートの **URL** から取ります。

### 手順

1. Google スプレッドシートを開く（使いたい車両用のシート）
2. ブラウザのアドレスバーにある URL を確認

例：
```
https://docs.google.com/spreadsheets/d/ 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms  /edit#gid=0
                                    ↑________________________________________________↑
                                    この「/d/」と「/edit」の間の部分が ID
```

3. **`/d/` の直後から `/edit` の直前まで**の文字列をコピー → それが **GOOGLE_SHEETS_SPREADSHEET_ID** です。

| 環境変数 | 中身 |
|----------|------|
| **GOOGLE_SHEETS_SPREADSHEET_ID** | スプレッドシート URL の `/d/` と `/edit` の間の文字列（英数字） |

---

## 3. .env.local に書くときの例

```env
# Supabase（Settings → API でコピー）
NEXT_PUBLIC_SUPABASE_URL=https://あなたのプロジェクトID.supabase.co
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...（長い文字列）

# スプレッドシート（URL の /d/ と /edit の間）
GOOGLE_SHEETS_SPREADSHEET_ID=1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms
```

値の前後に余分なスペースや引用符を付けないでください。`=` の右にそのまま貼り付けます。

---

## スプレッドシート連携でさらに必要なもの

車両・サマリーをスプレッドシートから読むには、上に加えて **Google サービスアカウント** の認証情報が必要です。

- **GOOGLE_SERVICE_ACCOUNT_JSON** … サービスアカウントの JSON を1行にしたもの  
  または  
- **GOOGLE_APPLICATION_CREDENTIALS** … その JSON ファイルのパス（例: `./sa.json`）

サービスアカウントの作り方・JSON のダウンロードは [Google Cloud Console](https://console.cloud.google.com/) の「IAM と管理」→「サービスアカウント」で行います。詳しくは `.env.example` や [SETUP_AND_INTEGRATION.md](SETUP_AND_INTEGRATION.md) を参照してください。
