# PWA（ホーム画面に追加）セットアップガイド

スマホのホーム画面から **1タップで起動** できるようにする手順です。

## 1. マニフェストの配置済み項目

- **`public/manifest.json`** を配置済みです。
- **`app/layout.tsx`** で `manifest: '/manifest.json'` と `appleWebApp` を指定済みです。

## 2. アイコンの準備（推奨）

ホーム画面に表示されるアイコンを用意してください。

| ファイル           | サイズ   | 配置場所        |
|--------------------|----------|-----------------|
| `icon-192.png`     | 192×192  | `public/`       |
| `icon-512.png`     | 512×512  | `public/`       |

- アプリのロゴや「M」マークなどを PNG で作成し、上記のファイル名で `public/` に保存します。
- 未配置の場合は、ブラウザのデフォルトアイコンが使われます。

## 3. スマホで「ホームに追加」する手順

### iPhone（Safari）

1. Safari でアプリの URL を開く（例: `https://your-app.vercel.app`）
2. 画面下部の **共有** ボタン（□に↑）をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前を確認して **「追加」** をタップ

→ ホーム画面にアイコンが追加され、タップでアプリが起動します。

### Android（Chrome）

1. Chrome でアプリの URL を開く
2. メニュー（⋮）→ **「アプリをインストール」** または **「ホーム画面に追加」**
3. 表示に従って追加

→ ホーム画面またはアプリ一覧に追加され、1タップで起動します。

## 4. 本番環境での注意

- **HTTPS** で配信されている必要があります（Vercel などは標準で HTTPS）。
- `manifest.json` とアイコンは `https://あなたのドメイン/manifest.json` などでアクセスできるようにしてください（Next.js の `public/` はそのままルートで配信されます）。

## 5. 動作確認

- Chrome DevTools → **Application** タブ → **Manifest** でマニフェストが読み込まれているか確認できます。
- **Lighthouse** の「Progressive Web App」で PWA の要件を確認できます。
