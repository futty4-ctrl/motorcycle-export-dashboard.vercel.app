# 月間50台ピック時のAPI・サービス費用目安

このアプリが接続している主なAPIと、**月50台**程度を扱う場合の費用感です。

---

## 1. 利用しているAPI・サービス一覧

| サービス | 用途 | 課金の有無 |
|----------|------|------------|
| **Google Gemini API** | 写真一括解析・厳格鑑定・4mini鑑定・BDS査定（画像/テキスト） | 従量課金（トークン・画像） |
| **Supabase** | 車両・査定・シナリオ・Bad Case 等のDB | 無料枠あり |
| **Google Drive** | 車両ごとフォルダ・写真保存・解析用画像取得 | 無料枠 15GB/アカウント |
| **Google Sheets** | 車両一覧・サマリー（任意） | 無料枠あり |
| **Exchange Rate API** | USD/JPY 取得（利益比較） | 無料枠あり（1500 req/月 等） |

※ BDS画像取り込み・ヤフオクスクレイプは「通常のHTTPアクセス」のため、API料金はかかりません。

---

## 2. 月50台で想定する「1台あたりの利用」

- **全50台**: 写真一括解析 1回（最大20枚/台）
- **そのうち約半数（25台）**: 厳格鑑定 or 4mini鑑定 を追加実行
- **そのうち約20件**: BDS査定（画像 or テキスト）で利益比較

※ 実際の運用で「毎台フル解析」でなければ、以下より安くなります。

---

## 3. 費用の内訳（月額・概算）

### Gemini API（メインのコスト）

- **モデル**: `gemini-2.5-flash`（デフォルト）
- **料金目安**（公式ベース）:  
  - 入力: 約 $0.30 / 100万トークン  
  - 出力: 約 $2.50 / 100万トークン  
  - 画像はトークン換算（1枚あたりおおよそ 数百〜千トークン程度と仮定）

**1回あたりのざっくり目安**（20枚写真＋プロンプトを1リクエストと仮定）:

- 写真一括解析（with grades）: 1リクエスト ≈ 入力 約3万トークン・出力 約1千トークン → **約 $0.01〜0.02**
- 厳格鑑定: 同程度 → **約 $0.01〜0.02**
- 4mini鑑定: 同程度 → **約 $0.01〜0.02**
- BDS査定（1画像 or テキスト）: **約 $0.001〜0.005**

**月50台の場合**:

- 写真解析 50回: 50 × $0.015 ≈ **$0.75**
- 厳格 or 4mini 25回: 25 × $0.015 ≈ **$0.38**
- BDS 20回: 20 × $0.003 ≈ **$0.06**

→ **Gemini 合計: 約 $1.2〜2.0 / 月（約 180〜300 円）**

※ 画像枚数・解像度・プロンプト長で変動します。多めに見て **月 300〜500 円**程度まで振れ幅を考えておくと安心です。

---

### Supabase

- **無料プラン**: DB 500MB、ストレージ 1GB、月 50K リクエスト程度まで。
- 月50台＋査定・シナリオ・Bad Case 程度なら、**無料枠内に収まる想定**です。
- 有料化しても Pro で約 $25/月 から。

→ **目安: 0 円（無料枠）**

---

### Google Drive

- **無料**: 15GB/Googleアカウント。
- 50台 × 20枚 × 約2MB ≈ 約2GB 程度なら **無料枠内**。
- それ以上増えると Google One 等のストレージ料金が発生します。

→ **目安: 0 円（〜2GB 程度まで）**

---

### Google Sheets

- 車両一覧・サマリー読み書き程度なら **無料枠で足りる**想定です。

→ **目安: 0 円**

---

### Exchange Rate API（exchangerate-api.com）

- 5分キャッシュ済みのため、リクエスト数は少なめ。
- 無料枠（例: 1500 req/月）で十分なことが多いです。

→ **目安: 0 円**

---

## 4. 月50台ピック時の「合計」目安

| 項目 | 月額（概算） |
|------|--------------|
| Gemini API | **約 200〜500 円**（運用の濃さで変動） |
| Supabase | 0 円（無料枠） |
| Google Drive | 0 円（〜2GB 程度） |
| Google Sheets | 0 円 |
| 為替API | 0 円 |
| **合計** | **約 200〜500 円/月** |

- 写真解析を「毎台だけ」に抑えれば **月 200〜300 円前後**、
- 厳格鑑定・4mini鑑定を多く使うと **月 400〜500 円前後** になりやすいイメージです。

---

## 5. コストを抑えるポイント

1. **写真解析だけ使う台数を決める**  
   全50台でなく「検討する台だけ」にすると Gemini 料金が減ります。
2. **厳格鑑定・4mini鑑定は必要台だけ**  
   候補を絞ってから実行すると、請求が抑えられます。
3. **画像サイズ**  
   解析に必要な解像度に抑えると、トークン数（＝料金）が減ります（現在は最大20枚まで取得）。
4. **為替**  
   環境変数 `FALLBACK_USD_JPY` を固定値にすると為替APIコールを減らせます（リアルタイム性は落ちます）。

---

## 6. 注意（APIキー・無料枠）

- **Gemini**: 無料枠（Tier 1 等）を超えると従量課金になります。Google Cloud の請求アラート設定を推奨します。
- **Supabase**: 無料プロジェクトの制限（DBサイズ・帯域）を超えると有料プランへ移行します。
- **Google**: Drive / Sheets は Google アカウントの利用規約・ストレージ制限の対象です。

上記は 2025〜2026 年時点の情報に基づく概算です。正式な料金は各サービスの最新の料金ページで確認してください。
